# QuizDuel API Integration Reference

This document serves as the official specification for connecting the native Android application to the QuizDuel Spring Boot backend (`springboot-backend`).

## 1. Network Configuration

### Base URLs
- **Android Emulator**: `http://10.0.2.2:5000/api/` (Note: Port 5000 is defined in `springboot-backend/src/main/resources/application.properties`)
- **Physical Device**: `http://<DEVELOPMENT_PC_LOCAL_IP>:5000/api/`
- **Production**: `https://<DEPLOYED_DOMAIN>/api/`

### Headers
- `Content-Type: application/json`
- `Authorization: Bearer <JWT_TOKEN>` (for all authenticated endpoints)

### Authentication Scheme
- Custom HS256 JWT generated by `com.quizduel.security.JwtService`.
- Expiration: 7 days.
- Claims: `id` (Long), `role` ("teacher" | "student"), `iat`, `exp`.

## 2. API Endpoints Specification

### 2.1 Authentication & Profile

#### Register User
- **Method / Path**: `POST /api/auth/register`
- **Access**: Public
- **Request Body**:
  ```json
  {
    "name": "Juan Dela Cruz",
    "email": "juan@school.edu.ph",
    "password": "password123",
    "school": "Mabini Elementary School",
    "role": "student"
  }
  ```
- **Response (201 Created)**:
  ```json
  {
    "token": "eyJhbGciOi...",
    "user": {
      "id": 1,
      "name": "Juan Dela Cruz",
      "email": "juan@school.edu.ph",
      "role": "student",
      "school": "Mabini Elementary School",
      "totalPoints": 0,
      "streak": 0
    }
  }
  ```

#### Login User
- **Method / Path**: `POST /api/auth/login`
- **Access**: Public
- **Request Body**:
  ```json
  {
    "email": "teacher@school.edu.ph",
    "password": "password123"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "token": "eyJhbGciOi...",
    "user": {
      "id": 1,
      "name": "Mrs. Santos",
      "email": "teacher@school.edu.ph",
      "role": "teacher",
      "school": "Mabini Elementary School",
      "totalPoints": 0,
      "streak": 0
    }
  }
  ```

#### Get Current User (`me`)
- **Method / Path**: `GET /api/auth/me`
- **Access**: Authenticated (`Authorization: Bearer <token>`)
- **Response (200 OK)**:
  ```json
  {
    "user": {
      "id": 1,
      "name": "Mrs. Santos",
      "email": "teacher@school.edu.ph",
      "role": "teacher",
      "school": "Mabini Elementary School",
      "totalPoints": 0,
      "streak": 0
    }
  }
  ```

### 2.2 Sections & Classes

#### List Sections
- **Method / Path**: `GET /api/sections`
- **Access**: Authenticated
  - *Teacher*: Returns sections owned by the teacher (with `studentCount`).
  - *Student*: Returns sections the student has joined.
- **Response (200 OK)**:
  ```json
  [
    {
      "id": 1,
      "name": "Grade 3 - Mabini",
      "gradeLevel": "Grade 3",
      "subject": "Araling Panlipunan",
      "joinCode": "MABINI",
      "battleTime": "15:00",
      "weekendBattles": false,
      "studentCount": 8
    }
  ]
  ```

#### Create Section
- **Method / Path**: `POST /api/sections`
- **Access**: Teacher only
- **Request Body**:
  ```json
  {
    "name": "Grade 3 - Rizal",
    "gradeLevel": "Grade 3",
    "subject": "Araling Panlipunan",
    "memberEmails": ["ana@school.edu.ph"]
  }
  ```
- **Response (201 Created)**: `SectionDto`

#### Join Section
- **Method / Path**: `POST /api/sections/join`
- **Access**: Student only
- **Request Body**:
  ```json
  {
    "joinCode": "MABINI"
  }
  ```
- **Response (201 Created or 200 OK)**:
  ```json
  {
    "joined": true,
    "section": {
      "id": 1,
      "name": "Grade 3 - Mabini",
      "gradeLevel": "Grade 3",
      "subject": "Araling Panlipunan",
      "joinCode": "MABINI",
      "battleTime": "15:00",
      "weekendBattles": false
    }
  }
  ```

#### Update Section
- **Method / Path**: `PUT /api/sections/{id}`
- **Access**: Teacher only
- **Request Body**:
  ```json
  {
    "name": "Grade 3 - Mabini Updated",
    "gradeLevel": "Grade 3",
    "subject": "Araling Panlipunan",
    "battleTime": "14:30",
    "weekendBattles": true
  }
  ```
- **Response (200 OK)**: `SectionDto`

#### Delete Section
- **Method / Path**: `DELETE /api/sections/{id}`
- **Access**: Teacher only
- **Response (204 No Content)**

#### Get Section Roster
- **Method / Path**: `GET /api/sections/{id}/roster`
- **Access**: Teacher only
- **Response (200 OK)**:
  ```json
  [
    {
      "id": 2,
      "name": "Ana Cruz",
      "email": "ana@school.edu.ph",
      "points": 480,
      "streak": 0,
      "rank": "History Buff"
    }
  ]
  ```

#### Add Students by Email
- **Method / Path**: `POST /api/sections/{id}/roster`
- **Access**: Teacher only
- **Request Body**:
  ```json
  {
    "emails": ["student1@school.edu.ph", "student2@school.edu.ph"]
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "added": [...],
    "notFound": [...],
    "alreadyIn": [...]
  }
  ```

#### Remove Student
- **Method / Path**: `DELETE /api/sections/{id}/roster/{studentId}`
- **Access**: Teacher only
- **Response (204 No Content)**

### 2.3 Questions & Topics (Teacher)

#### List Topics
- **Method / Path**: `GET /api/topics?sectionId=`
- **Access**: Teacher only
- **Response (200 OK)**:
  ```json
  [
    {
      "id": 1,
      "sectionId": 1,
      "sectionName": "Grade 3 - Mabini",
      "name": "Filipino Heroes",
      "questionCount": 4,
      "createdAt": "2026-11-17T08:00:00"
    }
  ]
  ```

#### Create Topic
- **Method / Path**: `POST /api/topics`
- **Access**: Teacher only
- **Request Body**: `{"sectionId": 1, "name": "Philippine Geography"}`

#### Rename Topic
- **Method / Path**: `PUT /api/topics/{id}`
- **Access**: Teacher only
- **Request Body**: `{"name": "National Symbols & Heritage"}`

#### Copy Topic
- **Method / Path**: `POST /api/topics/{id}/copy`
- **Access**: Teacher only
- **Request Body**: `{"sectionId": 2, "copyQuestions": true}`

#### Delete Topic
- **Method / Path**: `DELETE /api/topics/{id}`
- **Access**: Teacher only
- **Response (204 No Content)**

#### List Questions
- **Method / Path**: `GET /api/questions?sectionId=&topic=`
- **Access**: Teacher only
- **Response (200 OK)**:
  ```json
  [
    {
      "id": 1,
      "sectionId": 1,
      "topic": "Filipino Heroes",
      "text": "Who is the national hero of the Philippines?",
      "choices": {
        "A": "Jose Rizal",
        "B": "Andres Bonifacio",
        "C": "Emilio Aguinaldo",
        "D": "Antonio Luna"
      },
      "correctAnswer": "A",
      "difficulty": "Easy"
    }
  ]
  ```

#### Create Question
- **Method / Path**: `POST /api/questions`
- **Access**: Teacher only
- **Request Body**:
  ```json
  {
    "sectionId": 1,
    "topic": "Filipino Heroes",
    "text": "Who wrote Noli Me Tangere?",
    "choices": { "A": "Jose Rizal", "B": "Andres Bonifacio", "C": "Juan Luna", "D": "Mabini" },
    "correctAnswer": "A",
    "difficulty": "Easy"
  }
  ```

#### Update Question
- **Method / Path**: `PUT /api/questions/{id}`
- **Access**: Teacher only

#### Delete Question
- **Method / Path**: `DELETE /api/questions/{id}`
- **Access**: Teacher only

### 2.4 Battles & Quizzes

#### Generate Today's Battles (Teacher)
- **Method / Path**: `POST /api/battles/generate`
- **Access**: Teacher only
- **Request Body**:
  ```json
  {
    "sectionId": 1,
    "battleTime": "15:00",
    "weekendBattles": false
  }
  ```
- **Response (201 Created or 200 OK)**:
  ```json
  {
    "created": 4,
    "alreadyExisted": false,
    "date": "2026-11-17",
    "topic": "Filipino Heroes"
  }
  ```

#### Get Today's Battles (Teacher)
- **Method / Path**: `GET /api/battles/today?sectionId=`
- **Access**: Teacher only
- **Response (200 OK)**: `List<BattleRow>`

#### Get Battle Log (Teacher)
- **Method / Path**: `GET /api/battles/log?sectionId=&limit=`
- **Access**: Teacher only
- **Response (200 OK)**: `List<BattleRow>`

#### Student: My Today's Battles
- **Method / Path**: `GET /api/battles/me/today`
- **Access**: Student only
- **Response (200 OK)**:
  ```json
  [
    {
      "id": 1,
      "sectionId": 1,
      "date": "2026-11-17",
      "topic": "Filipino Heroes",
      "status": "pending",
      "statusLabel": "Pending",
      "result": null,
      "player1Score": 0,
      "player2Score": 0,
      "player1": "Ana Cruz",
      "player2": "Practice Bot",
      "winner": null,
      "battleTime": "15:00"
    }
  ]
  ```

#### Battle Detail (Interactive Quiz)
- **Method / Path**: `GET /api/battles/{id}`
- **Access**: Teacher or Player in battle
- **Response (200 OK)**:
  ```json
  {
    "id": 1,
    "sectionId": 1,
    "date": "2026-11-17",
    "topic": "Filipino Heroes",
    "status": "pending",
    "statusLabel": "Pending",
    "result": null,
    "player1Score": 0,
    "player2Score": 0,
    "player1": "Ana Cruz",
    "player2": "Practice Bot",
    "winner": null,
    "questions": [
      {
        "id": 1,
        "text": "Who is the national hero of the Philippines?",
        "choices": {
          "A": "Jose Rizal",
          "B": "Andres Bonifacio",
          "C": "Emilio Aguinaldo",
          "D": "Antonio Luna"
        }
      }
    ]
  }
  ```
  *(Note: `correctAnswer` is omitted for students while battle is pending/in_progress, revealed once completed).*

#### Submit Answers (Student)
- **Method / Path**: `POST /api/battles/{id}/answers`
- **Access**: Student player in battle
- **Request Body**:
  ```json
  {
    "answers": [
      { "questionId": 1, "selected": "A", "timeTaken": 4.5 }
    ]
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "score": 1,
    "total": 1,
    "battle": {
      "id": 1,
      "status": "completed",
      "player1Score": 1,
      "player2Score": 0,
      "winner": "Ana Cruz"
    }
  }
  ```

### 2.5 Insights, Leaderboards, & Badges

#### Teacher Dashboard
- **Method / Path**: `GET /api/dashboard?sectionId=`
- **Access**: Teacher only
- **Response (200 OK)**:
  ```json
  {
    "stats": { "activeBattles": 1, "students": 8, "averageScore": 75, "sections": 1 },
    "topicMastery": [{ "topic": "Filipino Heroes", "percent": 82 }],
    "todaysBattles": [...]
  }
  ```

#### Teacher Analytics
- **Method / Path**: `GET /api/analytics?sectionId=`
- **Access**: Teacher only

#### Leaderboard
- **Method / Path**: `GET /api/leaderboard?sectionId=&sectionIds=`
- **Access**: Authenticated (Teacher or Student)
- **Response (200 OK)**:
  ```json
  [
    {
      "position": 1,
      "studentId": 2,
      "name": "Ana Cruz",
      "sectionId": 1,
      "sectionName": "Grade 3 - Mabini",
      "points": 480,
      "streak": 1,
      "rank": "Kasaysayan Master"
    }
  ]
  ```

- **Access**: Authenticated
- **Response (200 OK)**:
